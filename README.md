# 短剧剧本工作台 · duanju-script-studio

一个 [WorkBuddy](https://www.workbuddy.cn/) 用户级技能（v1.3.2），用于中文付费短剧与 AI 漫剧的**文字剧本生产**：从一句话主题或一段小说原文，一路写到剧本雏形、70–80 集分集大纲、逐集细纲、标准格式分集剧本，按秒级节奏密度排布，并可续接成适合 AI 视频生成的分镜表。

只产出文字交付件，不生成图片或视频，不编译视频模型提示词。

## 生产线

```
主题立项（只有一句主题时） → 大纲（70–80 集） → 逐集细纲（含节奏时间轴） → 标准格式分集剧本 → AI 分镜四步
```

| 工位 | 交付物 | 主要参考 |
|---|---|---|
| 0 · 主题立项 | 四栏解码 + 人物三件套 + 2–4 分钟对话戏（含一次立场反转）+ 能否撑 70 集的出口判据 | `references/11-premise-to-script.md` |
| 1 · 大纲 | 总纲 + 分集大纲，含三个主反转、人物弧光与全季节奏档位曲线 | `references/01-outline-agent.md` |
| 2 · 细纲 | 每集带时间码的动作节点 + 完整节奏时间轴 + 结尾钩子 | `references/02-beat-agent.md`、`09-rhythm-grid.md` |
| 3 · 剧本 | 符合中文短剧排版规范的分集剧本 | `references/03-script-agent.md`、`04-format-spec.md` |
| 4 · 分镜 | 情绪图谱 → 视觉风险预控 → 防穿模分镜 → 纵向模板 | `references/05-storyboard-pipeline.md` |

五套资产贯穿全程：排版硬规范（`04`）、秒级节奏密度表（`09`）、情绪微表情库（`06`）、爆款六规律（`07`）、已装编剧技能协同地图（`10`）。文风改写工具箱（`08`）是旁支，其中「博主闲聊体」与「学术／论文润色」两区**禁止进入剧本台词**——这是本技能最核心的一条隔离规则。

## 秒级节奏密度

口诀：**3 秒一冲突、5 秒一爆点、6 秒一巴掌、15 秒一个包袱、30 秒一个反转、每 8–11 秒一个笑点。**

三条关键判断，照抄口诀会写坏：

1. **六条是两条并行轴，不是排队执行。** 张力轴（冲突 / 爆点 / 巴掌位 / 反转）与喜剧轴（笑点 / 包袱）叠加在同一条时间线上，同一秒可以同时命中两轴。
2. **「3 秒一冲突」是密度上限，不是数量指标。** 意思是观众任意时刻回看 3 秒，对抗仍在升级；一个持续加码的冲突可以覆盖多个窗口，不是每 3 秒换一个新矛盾。
3. **「6 秒一巴掌」是打脸爽点的可替换位，不是真扇耳光。** 虐恋换成「一句话钉住对方」，悬疑换成证据打脸；字面暴力按 `05` 降维成侧面暗示 + 精准音效。

另外：**每 35 秒内至少给一次 5–8 秒呼吸段，反转之后必给**（满档 90 秒骨架实际排到 15–24 秒一次，更密不算错）；70–80 集不能集集满档，要有降档集与呼吸集。集内 30 秒反转与跨集主反转不是一个尺度。完整定义、90 秒时间轴骨架、按题材调节系数见 `references/09-rhythm-grid.md`。

## 剧本排版规范速览

| 元素 | 写法 |
|---|---|
| 场序 | `场3-2 日/内 体育场 主要人物：张三、李四` |
| 动作 / 特效 | `△沈知初手里拿着病例报告一步步踏上天台楼梯。` |
| 对话 | `医生：抱歉沈小姐，你的诊断结果是胃癌晚期。` |
| 说话状态 | `沈知初（慢慢转身）：如果有一天，我快死了，你会不会想我啊。` |
| 首次出场字幕 | `……满是鲜血。【字幕：沈知初，厉家夫人】` |
| 群演豁免 | `（本集群演：司仪、宾客甲、路人甲）`，集首声明后免挂人物字幕 |
| 时间信息 | `（时间字幕：1987年）`，不写成 `【字幕：…】` |
| 内心活动 | `沈知初内心os：厉景深，如你所愿，我要放过你了……` |
| 闪回 | `【闪回】` … `【闪回结束】`，内部仍写完整场序 |

每集场景不超过 5 个，场序连续。时间码只写在细纲与时间轴里，不写进剧本正文。完整规范与范例见 `references/04-format-spec.md`。

## 与已装编剧技能协同

本技能只占「中文短剧 70–80 集文字交付件」这一段，其余工位交给已装技能：立项 (`short-story-pitch` / `script-craft-1-framework`)、跨集连续性 (`l1ang-drama`)、逐句台词 (`script-craft-4-dialogue`)、圆桌会诊 (`script-craft-3-doctor`)、题材专精 (`infinite-thriller-scriptwriting` / `sitcom-writers-room`)、分镜与资产 (`manju-production-suite` / `seedance-shotlist-director`)。完整能力地图、三条连招与冲突仲裁见 `references/10-writer-skills-map.md`。

**交接铁律**：外部技能改完的稿子，不重跑下面两个校验脚本不交付。

## 安装

把整个 `duanju-script-studio/` 目录放到用户级技能目录：

- Windows：`C:\Users\<用户名>\.workbuddy\skills\`
- macOS / Linux：`~/.workbuddy/skills/`

新开一个对话即可生效。仓库根目录的 `SKILL.md` 是技能入口，目录名必须与 `SKILL.md` 里的 `name` 一致。也可以直接解压 WorkBuddy 生成的同名 zip 分发包，效果相同。

## 使用示例

直接说需求即可，技能会判断素材停在哪一级并从对应工位的规则执行：

- 「给我写个剧本，主题是重组家庭」（只有一句主题时走工位 0，先出可演雏形）
- 「写个 70 集大纲，题材是年代重生」
- 「把这段粗纲扩成第 3 集细纲，排个 90 秒时间轴」
- 「按细纲写第 1 集，△ 动作行那种格式」
- 「这段太拖了，按 3 秒一冲突重排」
- 「这段台词太 AI 了，改口语一点」
- 「跟已装编剧技能怎么配合 / 这段该交给谁」
- 「把这段小说原文做成漫剧分镜」

## 两个校验脚本

需要 Python 3，无第三方依赖。

```bash
# 剧本格式：场序（含场号后缺空格）、△ 动作行、说话状态位置、内心os、闪回配对、
#           场景数、字幕覆盖（群演可声明豁免）、年代误写成人物字幕、文风禁用词
python scripts/check_format.py <剧本文件路径>

# 节奏时间轴：锚点齐全度、空档、呼吸段、类型单调、字面暴力、未知类型、未填占位符
python scripts/check_rhythm.py <时间轴文件> --mode full
```

`--mode` 支持 `full`（打脸爽剧默认档）、`comedy`（喜剧向满档）、`romance`（虐恋）、`suspense`（悬疑）、`light`（降档集）。选错档位会把合格稿子判成不合格，跑之前先定题材。节奏校验器的 WARN 不阻断交付，按报告人工判断；空白模板整篇都是占位符时只汇总成一条提示，不逐行刷屏。

两个脚本都按 `utf-8-sig` 读文件，Windows 记事本另存的 UTF-8（带 BOM）不会让首行失检；时间轴的竖线与冒号半角全角都认（`|` 与 `｜`、`:` 与 `：`），中文输入法直接敲不会解析失败；只写了两列 `分:秒｜内容` 的细纲节点会被单独提示「缺类型列，请另附时间轴」，而不是笼统报「未解析到锚点」。

三条硬判定：**反转之后 12 秒内没有呼吸段判 ERROR**（反转即结尾时自动豁免）；**字面暴力按正则匹配**，`扇婆婆耳光`、`抽了她一巴掌` 这类插入写法都能识别，不会被词表绕过；**说话状态写成 `人物名：（动作）台词` 判 ERROR**，规范是括号在冒号前。反转按 30 秒周期查、容差 45 秒，并把「最后一个反转到片尾」计入，所以 90 秒单集至少三个反转。
