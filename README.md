# 短剧剧本工作台 · duanju-script-studio

一个 [WorkBuddy](https://www.workbuddy.cn/) 用户级技能，用于中文付费短剧与 AI 漫剧的**文字剧本生产**：从一句话题材，一路写到 70–80 集分集大纲、逐集细纲、标准格式分集剧本，并可续接成适合 AI 视频生成的分镜表。

只产出文字交付件，不生成图片或视频，不编译视频模型提示词。

## 生产线

```
大纲（70–80 集） → 逐集细纲 → 标准格式分集剧本 → AI 分镜四步
```

| 工位 | 交付物 | 主要参考 |
|---|---|---|
| 1 · 大纲 | 总纲 + 分集大纲，含三个主反转与人物弧光 | `references/01-outline-agent.md` |
| 2 · 细纲 | 每集 6–10 个可执行动作节点 + 结尾钩子 | `references/02-beat-agent.md` |
| 3 · 剧本 | 符合中文短剧排版规范的分集剧本 | `references/03-script-agent.md`、`04-format-spec.md` |
| 4 · 分镜 | 情绪图谱 → 视觉风险预控 → 防穿模分镜 → 纵向模板 | `references/05-storyboard-pipeline.md` |

三套资产贯穿全程：排版硬规范（`04`）、情绪微表情库（`06`）、爆款五规律（`07`）。文风改写工具箱（`08`）是旁支，其中「博主闲聊体」与「学术／论文润色」两区**禁止进入剧本台词**——这是本技能最核心的一条隔离规则。

## 剧本排版规范速览

| 元素 | 写法 |
|---|---|
| 场序 | `场3-2 日/内 体育场 主要人物：张三、李四` |
| 动作 / 特效 | `△沈知初手里拿着病例报告一步步踏上天台楼梯。` |
| 对话 | `医生：抱歉沈小姐，你的诊断结果是胃癌晚期。` |
| 说话状态 | `沈知初（慢慢转身）：如果有一天，我快死了，你会不会想我啊。` |
| 首次出场字幕 | `……满是鲜血。【字幕：沈知初，厉家夫人】` |
| 内心活动 | `沈知初内心os：厉景深，如你所愿，我要放过你了……` |
| 闪回 | `【闪回】` … `【闪回结束】`，内部仍写完整场序 |

每集场景不超过 5 个，场序连续。完整规范与范例见 `references/04-format-spec.md`。

## 安装

把整个 `duanju-script-studio/` 目录放到用户级技能目录：

- Windows：`C:\Users\<用户名>\.workbuddy\skills\`
- macOS / Linux：`~/.workbuddy/skills/`

新开一个对话即可生效。仓库根目录的 `SKILL.md` 是技能入口，目录名必须与 `SKILL.md` 里的 `name` 一致。

也可以解压同目录上层的 `duanju-script-studio.zip`（如果随仓库一起提供）。

## 使用示例

直接说需求即可，技能会判断素材停在哪一级并从对应工位的规则执行：

- 「写个 70 集大纲，题材是年代重生」
- 「把这段粗纲扩成第 3 集细纲」
- 「按细纲写第 1 集，△ 动作行那种格式」
- 「这段台词太 AI 了，改口语一点」
- 「把这段小说原文做成漫剧分镜」

## 格式校验

成稿后运行（需要 Python 3，无第三方依赖）：

```bash
python scripts/check_format.py <剧本文件路径>
```

检查场序连续性、每集场景数、`△` 动作行、内心 OS 写法、闪回是否成对、有台词角色的字幕覆盖，以及博主腔／学术腔／互联网黑话是否误入台词。有 ERROR 时退出码为 1。

```
│   ├── 05-storyboard-pipeline.md     # AI 适配型分镜四步法
│   ├── 06-emotion-library.md         # 哀 / 怒 / 喜 / 惊微表情库
│   ├── 07-hit-rules.md               # 爆款五规律与钩子公式

├── assets/
│   ├── 剧本空白模板.md                # 可直接复制的分集剧本骨架
│   └── 分镜纵向模板.md                # step.04 逐镜输出模板
└── scripts/
    └── check_format.py               # 剧本格式校验器
```
