# 工位 4 · AI 适配型分镜四步法

把一段小说原文或分集剧本，转成适合可灵 / 即梦等 AI 视频模型生成的分镜表。四步必须**按顺序执行**，后一步显式引用前一步的结论，不另起炉灶。

适用：漫剧、AI 短剧、小说改视频。输入通常是小说原文片段或已定稿的分集剧本。

> 两版原始提示词内容高度重复，本文件已合并去重，并保留两版各自的独有要求（全景至特写镜头清单、面部表情不过分夸张、音效代偿的具体示例等）。

## 四步交接规则

| 步骤 | 产出物 | 下一步必须引用 |
|---|---|---|
| step.01 | 情绪节奏图谱 + 连续动作拆解 | step.02 用图谱定微表情基线，用动作链定标志性动作图 |
| step.02 | 生图 / 视频素材清单（含四类风险预控） | step.03 按清单拆镜，缺素材的镜头不硬设计 |
| step.03 | AI 适配型分镜脚本初稿 | step.04 逐镜精炼台词并套纵向模板 |
| step.04 | 纵向标准分镜表（可直接导入提词器） | 交付 |

---

## step.01 剧情拆解与动作逻辑

**身份定位**：对原著保持高度尊重的资深漫剧内容策划与动作设计专家，精通影视视听语言，能精准把控观众的情绪起伏与观看节奏。

**核心要求**：在**不生成任何画面内容**的前提下，严格忠于原著设定，仅用简洁文字完成以下两项分析，作为后续所有镜头制作的核心指导依据。不擅自改设定、不补原著没有的情节。

**1. 情绪节奏图谱**
- 用 3–5 个核心关键词勾勒本段内容的情感变化轨迹。
- 准确定位【爽点 / 泪点 / 燃点】的爆发时刻，并写明对应的**具体剧情节点**（哪句话、哪个动作之后），不写"中段""高潮部分"这类模糊位置。

**2. 连续动作拆解**
- 若原文包含关键打斗、施法或连贯动作场景，拆解为完整动作链条：`初始姿态 → 过程动态 → 最终定格`。
- 目的是确保后续视频生成时动作连贯自然，避免瞬移、断层等物理错误。
- 链条上每一环都要能对应到一镜的首帧或尾帧状态。

**原文输入区**：〔在此处粘贴小说原文片段或分集剧本〕

## step.02 视觉元素梳理与风险预控清单

**身份定位**：行业顶尖的影视美术指导与角色造型设计师。

**核心要求**：基于 step.01 的分析结论与原文，全面提取所有视觉元素，整理出一份**最简明的生图 / 视频素材清单**，提前识别并规避生成难点。

### 角色视觉元素

- **外貌与服饰**：严格依据原文描述提取。原文表述模糊时，可合理补充符合人设的 AI 生图材质细节（发丝、布料、光泽），但**绝不擅自修改原著的核心设定**（年龄、身份、伤疤、法器形制、时代服制）。补充项须标注「补」。
- **情绪微表情**：把角色的核心情绪转成具体可呈现的微表情，词从 `06-emotion-library.md` 取。示例：隐忍的愤怒 = 牙关紧咬 + 咬肌紧绷 + 眼底泛红。
- **标志性动作**：提炼角色的习惯性动作（例如剑客双手抱剑、靠墙站立），避免 AI 生成不符合人设的随意姿态。以 step.01 的动作链为来源。

### 场景视觉元素

- 明确故事的**时代背景**与**主要光源方向**（自然光 / 顶光 / 侧逆光、光源位置、冷暖）。
- 列出所有需要制作的**全景至特写镜头**，并单独标出其中的全景空镜。
- 标注每个场景的固定视觉锚点（门的位置、道具摆放、色调），保证跨镜一致。

### 生成风险预控清单（必须单独列出）

本集内容中**至少需要提前制作**的素材，按四类输出，缺一类不得进入 step.03：

| 类别 | 用途 |
|---|---|
| 人物定妆图 | 锁住长相、服制、发型，防止跨镜变脸 |
| 标志性动作图 | 锁住姿态，防止 AI 随意摆姿势 |
| 场景空镜 | 锁住空间关系与光源，作为镜头基准 |
| 关键细节特写 | 法器、伤疤、特殊手势等，防止全景画面崩坏 |

## step.03 AI 适配型分镜脚本创作

**身份定位**：深谙 AI 视频生成模型（可灵、即梦）物理局限性、同时透彻研究短视频平台审核机制的专业漫剧导演。

**核心要求**：基于前两步结果，把小说剧情转成适合 AI 生成的分镜脚本初稿。严格遵守以下四大原则。

### 1 · 防穿模原则

禁止设计复杂的双人或多人肢体接触场面。所有互动拆解为：**单人特写 / 正反打对话镜头 / 主观视角的局部特写**，确保物理交互最小化。拥抱、掐脖、扭打、递物等一律拆分，用视线与局部道具建立关系，不靠同框肢体。

### 2 · 平台合规与暗示表达原则（重中之重）

- **暴力与敏感内容降维**：严禁出现断肢、大量流血或过度亲密画面。转化为侧面暗示——落地的武器、窗上的血影剪影、旁观者惊恐的面部反应、骤然熄灭的灯、被攥皱的衣角。
- **面部表情合理化**：表情不过分夸张，不用扭曲到失真的吼叫或哭喊脸；用 `06-emotion-library.md` 里的克制型微表情。
- **音效代偿机制**：因合规限制被削弱的视觉冲击力，用**精准音效**加倍补足（骨头断裂的闷响、利刃划破空气的破空声、布料撕裂声、骤停的脚步声），实现"画面干净，听觉震撼"。每一处被降维的冲击都要在分镜里写明替代音效。

### 3 · 动作连贯性原则

关键动作镜头必须在备注中注明**首帧起始状态与尾帧结束状态**。示例：上镜结束时水杯开始倾倒 → 下镜第一帧须承接水流向下的方向。以 step.01 的动作链为准，禁止首尾帧状态跳跃。

### 4 · 节奏与时长控制

- 普通文戏镜头单条 2–5 秒。
- 情绪爆发瞬间可用慢动作或快速推拉镜头，时长延长至 5–8 秒。
- 每条分镜只承载一个动作或一个信息点；信息点过多就拆镜。

**输出**：分镜脚本核心内容，排版格式不限，但四条原则必须逐条可核查。

## step.04 台词打磨与规范化输出

**身份定位**：兼具顶级台词润色专家与格式排版工程师的双重能力。

**核心要求**：对 step.03 的分镜脚本做最后两项优化。

**台词精炼**：把冗长的书面化对白与内心独白，压缩成简洁凝练、符合当代口语习惯的表达，并附上**明确情绪标签**（压低声音、带着怒意说、咬牙切齿地说）。内心独白能删则删，改用微表情与音效承担。遵循 `SKILL.md` 硬规则 3：不带入博主腔与学术腔。

**结构化输出**：严格按以下纵向模板逐条输出所有分镜，每条分镜之间用横线 `---` 分隔，便于直接导入提词器或文档。

```
【镜号】X
【时长】X秒
【景别与镜头运动】〈填写〉
【出场角色与画面描述（规避穿模与合规版）】〈填写具体内容，含微表情〉
【台词/旁白】〈填写润色后的台词〉
【精准音效/背景音乐】〈填写具体音效〉
【衔接说明与防穿模备注（含首尾帧动作承接）】〈填写物理衔接逻辑〉
---
【镜号】X+1
...
```

空白可复制版见 `assets/分镜纵向模板.md`。

## 交付前合规复查

- [ ] 无同框多人肢体接触
- [ ] 无断肢、大量流血、过度亲密画面；冲击点已用侧面暗示 + 精准音效替代
- [ ] 面部表情克制，无失真夸张
- [ ] 每个关键动作都写了首帧 / 尾帧承接
- [ ] 文戏 2–5 秒，情绪爆发 5–8 秒
- [ ] 四类预控素材清单齐全，分镜里没有依赖未制作素材的镜头
- [ ] 台词带情绪标签，无书面长句、无博主腔、无学术腔
