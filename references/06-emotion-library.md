# 情绪微表情库（哀 / 怒 / 喜 / 惊）

## 用法

写剧本 `△` 动作行、括号里的说话状态、分镜的画面描述、生图提示词的表演说明时，从这里**取具体可见的面部与肢体描述**，不要写"她很悲伤""他怒了""气氛压抑"这类抽象判断。

- 剧本：一条 `△` 取 1–2 个微表情即可，不堆砌。
- 分镜：把微表情写进【出场角色与画面描述】，并遵守 `05-storyboard-pipeline.md` 的"表情不过分夸张"要求。
- 生图：可直接把整条描述作为表情提示词，多个微表情之间用 `+` 连接。
- 强度递进：同类情绪按库内顺序大致由弱到强，例如「隐忍不哭 → 默默流泪 → 低声啜泣 → 崩溃大哭」。爆点前一镜用克制型，爆点当镜才用爆发型。

> 本库相对原始素材修正了明显错字（如「下辱前伸」→「下唇前伸」、「跟神看向别处」→「眼神看向别处」、「额头青新」→「额头青筋」、「嘴唇报紧」→「嘴唇抿紧」、「嘴龟着微笑」→「抿着微笑」、「手指住胸口」→「手指按住胸口」），语义未改。

## 哀 · 悲伤 / 委屈 / 崩溃

| 词条 | 可见描述 |
|---|---|
| 眼眶泛红 | 眼眶泛红，泪水在眼眶打转，眼神失焦，嘴唇微垂 |
| 空洞麻木 | 眼神失焦，瞳孔放大，表情僵硬，嘴角平直，像被抽空了灵魂 |
| 泪水滑落 | 一滴眼泪从眼角滑下，鼻尖泛红，眼神向下，嘴角微微下垂 |
| 隐忍不哭 | 眼眶泛红但死死忍住，嘴唇抿紧，下巴肌肉紧绷，鼻翼微缩 |
| 低声啜泣 | 用手捂住嘴，眼泪挂在脸颊，鼻翼抽动，肩膀微微颤抖 |
| 绝望闭眼 | 双眼紧闭，眉头紧皱，嘴角下拉，仿佛放弃了所有希望 |
| 崩溃大哭 | 双眼紧闭，泪水大量涌出，嘴巴张开哭喊状，表情扭曲 |
| 默默流泪 | 不做任何表情，眼泪无声从眼角滑落，脸上没有多余表情 |
| 委屈撇嘴 | 下唇前伸，嘴唇撅起，眉头微蹙，眼神躲闪，像要哭的样子 |
| 触景生情 | 眼神突然变得柔软，眼眶微湿，嘴角微微抽动，陷入回忆 |

## 怒 · 愤怒 / 憋屈 / 爆发

| 词条 | 可见描述 |
|---|---|
| 眉头紧锁 | 眉毛向下压成倒八字，眼神锋利，嘴唇抿紧，下巴微收 |
| 阴沉脸 | 表情完全放松但眼神冷冽，嘴角平直或微微下压，让人感觉低气压 |
| 咬牙切齿 | 牙关紧咬，太阳穴青筋微凸，眼神凶狠，鼻翼微微扩张 |
| 妒忌扭曲 | 嘴角向一侧拉扯，眼睛眯起，眉毛下压，鼻孔微微扩张，表情扭曲 |
| 冷眼相视 | 眼神冰冷，嘴角微抿，下巴微抬，面无表情但压迫感强 |
| 轻蔑不屑 | 单边嘴角上扬，眼睛斜视，下巴微抬，表情高傲 |
| 憋屈忍怒 | 嘴唇紧抿，眼皮微重，眼神向下避开，拳头微微攥紧 |
| 暴怒前兆 | 额头青筋微凸，嘴唇颤抖，呼吸急促，眼神像要喷火 |
| 爆发怒吼 | 嘴巴张大呈吼叫状，眉毛上扬，眼神瞪大，额头青筋暴起 |
| 生闷气 | 嘴巴嘟起，眉头紧锁，眼神看向别处，双臂交叉抱胸 |

| 甜蜜对视 | 嘴角轻轻翘起，眼睛含情脉脉，脸颊微红，眼神专注 |

## 惊 · 震惊 / 恐惧 / 害怕

| 词条 | 可见描述 |
|---|---|
| 瞳孔放大 | 眼睛瞪大，瞳孔放大，嘴巴微微张开，身体僵住 |
| 瞳孔地震 | 眼睛瞪大，瞳孔剧烈收缩，嘴巴微张，面部瞬间僵硬 |
| 惊恐后退 | 眼睛瞪圆，嘴巴张大成 O 型，身体后倾，双手抬起护在胸前 |
| 战栗恐惧 | 眼睛瞪大充满恐惧，嘴巴张开但发不出声，身体像被定住 |
| 难以置信 | 眼睛瞪大，眉毛上扬，嘴巴微张，头微微后仰 |
| 怀疑警惕 | 眼睛眯起，瞳孔收缩，头微微向后退，表情充满戒备 |
| 心虚躲闪 | 眼神飘忽，不敢直视，嘴角微微抽动，肩膀微缩 |
| 惊吓后怕 | 眼睛仍然瞪大，但表情开始放松，嘴唇颤抖，手指按住胸口 |
| 毛骨悚然 | 眼睛半眯，瞳孔缩小，嘴唇微张，后背紧绷，表情凝固 |

## 组合示例

| 情境 | 取词 |
|---|---|
| 隐忍的愤怒 | 咬牙切齿 + 眼底泛红（牙关紧咬、咬肌紧绷、鼻翼微微扩张、眼眶泛红） |
| 被当众羞辱还要撑住 | 憋屈忍怒 → 隐忍不哭，中间不切镜头，用微表情递进 |
| 反派听到真相 | 阴沉脸 → 瞳孔地震 → 轻蔑不屑（先压后破再装） |
| 打脸爽点落地 | 反派：瞳孔放大 + 难以置信；主角：暗爽得意（不写大笑，留余味） |
| 虐点收尾 | 默默流泪，禁止用崩溃大哭，留白给下一集钩子 |
