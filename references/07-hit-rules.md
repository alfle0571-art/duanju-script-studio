# 爆款六规律（创作准则层）

定大纲、定每集开头结尾、判断一版稿子能不能过时用这一份。六条是取舍标准，不是可选项。

## 规律一 · 开头 3 秒定生死

在 3 秒内抛出**反常理**钩子。

**公式：反常理设定 + 具体画面 + 情绪冲突，缺一不可。**

| 要素 | 要求 | 反例 |
|---|---|---|
| 反常理设定 | 一句话能说清"哪里不对劲" | "她的人生陷入低谷" |
| 具体画面 | 看得见的人、物、动作 | "气氛突然凝重" |
| 情绪冲突 | 观众立刻知道该替谁急 | "故事由此展开" |

**落到剧本**：第一集第一场的前三行内必须三要素齐备。参考 `04-format-spec.md` 的范例——第一行 `△` 是拿着病例报告上天台，第二行是特写「胃癌晚期」，第三行 `内心os` 是"我要放过你了"，三行内交代了绝症、赴死念头与一段不对等的关系。

**三种可直接套用的钩子**：
1. **身份反差**：追悼会上的"死者"坐起来了（`03-script-agent.md` 的司念示例）。
2. **时间错位**：寿衣、挽联上的 1987、街上的二八大杠，同时出现。
3. **规则颠覆**：本该被保护的人正被逼着去救伤害她的人。

**每集结尾**同样要留钩子，且必须是具体画面或具体一句话（病例报告落在地上、门被推开、手机亮起一条未读消息），不能写"留下悬念"。

> 开局 3 秒钩子是张力轴在 t=0 的特例；整集的秒级密度见规律六与 `09-rhythm-grid.md`。

## 规律二 · 强情绪，不堆特效

用户为情绪买单，不为特效。

落到执行：用 step.01 的情绪节奏图谱标出爽点 / 泪点 / 燃点的**具体剧情节点**，用 `06-emotion-library.md` 把情绪写成可见的微表情。爆点前一镜用克制型表情，爆点当镜才用爆发型。特效只用来强调关键信息（化验单特写、挽联特写），不用来替代情绪。

判断标准：删掉所有特效说明后，这一场还让不让人心里一紧？不紧就是情绪没写够，加特效也救不回来。

## 规律三 · 系列化 + IP 化，拒绝"一次性"

爆款正在从"单部剧"变成"IP 系列"。

落到执行：整季按 7–8 个叙事单元划分（见 `01-outline-agent.md`），每个单元结尾改变主角处境或认知；世界观里预留可再开一季的关系、组织或未解之谜；人物有可复用的标志性动作与口头禅，让观众能认、能被二创。避免把全部设定在第一季用尽。

## 规律四 · 效率不等于粗糙，精品才是出路

成本低 ≠ 可以粗糙。低质"PPT 漫剧"已被平台精准打击，精品化是唯一出路；"手搓"爆款正在颠覆"内容工厂"。

落到执行：进入工位 4 时，四类预控素材（人物定妆图 / 标志性动作图 / 场景空镜 / 关键细节特写）必须齐备才开镜；防穿模、音效代偿、首尾帧承接三条一条都不能省。省掉的不是成本，是成片的连贯性。

## 规律五 · 剧本是第一生产力

**套路化 = 死亡。**

落到执行：
- 相邻两集不得重复使用同一爽点类型，连续打脸不超过两集。
- 每 8–12 集至少一次中型反转或信息揭露；三个主反转分布见 `01-outline-agent.md`。这是**跨集宏观**尺度，不要与集内 30 秒反转混淆。
- 每个角色有独特声口，遮住名字能认出是谁在说话（见 `03-script-agent.md`）。
- 反转必须从人物动机里长出来，不靠"恰好路过听见""突然失忆"这类外力硬转。

## 规律六 · 密度是节奏，不是填满

把 **3 秒冲突、5 秒爆点、6 秒巴掌位、8–11 秒笑点、15 秒包袱、30 秒集内反转** 钉在时间轴上。但密度不等于从头密到尾：

- **两轴并行**：张力轴与喜剧轴叠加，同一秒可以同时命中，不是六条轮流。
- **呼吸段是硬要求**：每 25–35 秒给 5–8 秒低密度段，反转之后必给。删掉它们，后面所有爆点都会失效。
- **按题材调节**：虐恋 / 悬疑关闭喜剧轴；「6 秒一巴掌」是打脸爽点的可替换位，不是真扇耳光，字面暴力按 `05` 降维。
- **全季有起伏**：70–80 集全满档观众会疲劳、人物弧光没地方长。单元高潮集满档，过渡集降一档，每单元留 1 集呼吸集。

完整的双轴模型、六锚点定义、90 秒时间轴骨架、题材档位与校验器用法见 `09-rhythm-grid.md`。

## 一版稿子的快速质检

- [ ] 第一集前三行：反常理设定 / 具体画面 / 情绪冲突，三项都在
- [ ] 每集结尾是具体画面或具体台词，不是抽象悬念
- [ ] 爽点 / 泪点 / 燃点能指到具体剧情节点
- [ ] 情绪写成了可见微表情，不是形容词
- [ ] 时间轴两轴分别排过，六类锚点按题材档位齐全
- [ ] 每 25–35 秒有呼吸段，反转后必有；全季标了节奏档位
- [ ] 集内 30 秒反转没被误写成跨集主反转
- [ ] `scripts/check_rhythm.py` 已按题材档位跑过
- [ ] 相邻两集爽点类型不重复
- [ ] 特效只承担关键信息，没有拿来掩盖情绪空档
- [ ] 世界观里还留着下一季能用的东西
- [ ] 分镜稿的四类预控素材齐备
