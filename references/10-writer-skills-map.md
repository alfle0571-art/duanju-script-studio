# 已安装编剧技能协同地图

## 先说判断

这些技能不是 20 个备选方案，是**一条更大的生产链上的不同工位**。「综合」的意思不是把能力全塞进本技能，而是三件事：

1. 知道哪一段活该交给谁；
2. 交出去时带齐上游产物，拿回来时重跑本技能的格式校验；
3. 两个技能都能干时，有明确的仲裁规则，不来回踢皮球。

本技能占据的只有一段：**中文付费短剧 / AI 漫剧的 70–80 集文字交付件，以及中国式 `△` / `场x-x` 排版规范**。这一段之外，本技能说了不算。

## 全景分组

### A · 立项与框架（本技能之前）

| 技能 | 能力 | 什么时候用 | 与本技能的关系 |
|---|---|---|---|
| `short-story-pitch` | 选题立项书：赛道、情绪标签、篇幅档位、差异化、过 / 改 / 毙 | 「这个点子行吗」「值不值得写」 | 前置可选。定下来再进工位 1 |
| `script-craft-1-framework` | 项目档案 + 剧本框架（题材定位 → 人设 → 分集骨架） | 「从零起架子」「先想清楚要写什么」 | 前置可选。它的分集骨架可当工位 1 的输入，但**集数规格以本技能 70–80 集为准** |
| `novel-to-screenplay` | 小说 → 剧集圣经、人物小传、treatment、提案、剧本样稿 | 「这小说能拍成什么」「给投资人看的东西」 | 前置。给的是说服人的开发材料，不是可拍交付件；定稿后转本技能工位 3 |
| `moke-worldbuilding` | 世界观设定 + 九张双语图像提示词 | 「搭个世界」「先把设定立住」 | 并行。玄幻 / 年代 / 无限流题材先立世界，再进工位 1 |
| `microdrama-storyforge` | 15 集竖屏短剧的题材重构、成本控制、强钩子、合规检查 | 「红果那种」「15 集怎么排」 | 见「冲突仲裁」。集数规格不同，但题材重构与成本思路可借用 |

### B · 大纲与正文（本技能主场）

| 技能 | 能力 | 什么时候用 | 与本技能的关系 |
|---|---|---|---|
| **`duanju-script-studio`** | 70–80 集大纲 → 逐集细纲 → 标准格式分集剧本 → AI 分镜四步 | 本技能触发词见 `SKILL.md` | 主场 |
| `script-creation-generator` | 一句话 → 完整剧本，Stage 0–10 带闸门与交付自检 | 「我有个想法，从头到尾给我一版」 | 替代路径。它管通用形态，本技能管中文短剧排版与集数规格，两者不合并 |
| `script-craft-2-fill` | 把大纲扩写成正文，需 script-craft-1 的项目档案前置 | 「按这个大纲写出来」「这场戏写细点」 | 连招下游。产物若为中文短剧，回来按 `04` 重排 |
| `script-forging` | 故事 → 形态建议 → 分场 → 标准剧本 → 分镜 → 数字资产清单，一条龙 | 「写成能拍的」「连分镜和道具一起要」 | 更宽的一条龙；本技能更窄更深。要资产清单时交给它 |
| `l1ang-drama` | 竖屏短剧硬门禁、剧本转镜头单元、首尾帧交接、跨集修复与终审 QA | 「每集接不上」「人物前后不一样」「台词时长对不上」 | **后置强搭档**。本技能成稿后交给它验连续性 |
| `write-script`（写剧本） | 解说视频脚本，每场只有「画面」「旁白」两行 | 「改成解说」「配旁白的稿子」 | 不同媒介，直接转介 |
| `write-story`（写故事） | 家庭回忆文章，五节四百字 | 「写写我们家的事」 | 非剧本，转介 |
| `story-short-write` | 短篇网文，设定 / 小节大纲 / 正文三文件 | 「写个短篇」「要那种让人心里堵的」 | 非剧本，转介 |

### C · 诊断与台词（成稿之后 / 并行）

| 技能 | 能力 | 什么时候用 | 与本技能的关系 |
|---|---|---|---|
| `screenwriting-pro` | 单人编剧视角，改 / 续 / 诊，主角行动与压力选择 | 「这个剧本不太行」「结构松」「接不下去了」 | 后置。改完必须重跑 `check_format.py` |
| `script-craft-3-doctor` | 模拟 4–6 位行业评委轮替会诊，输出带优先级的修改清单 | 「找几个人评评」「圆桌会诊」 | 后置。只诊断不开方，开方回 `screenwriting-pro` |
| `script-craft-4-dialogue` | 逐句七维台词诊断与改写，每条建议必须带理由 | 「台词太假」「每个人说话都一样」 | **后置强搭档**。本技能 `03` 管写出来，它管逐句磨 |
| `tig-scene-engine` | 单场戏五要素（目标 / 阻碍 / 战术 / 反转 / 价值转变）审计 | 「这场戏没劲」「冲突不够」 | 单场急救，与本技能 `09` 节奏表互补：它管戏有没有劲，09 管多久给一次 |
| 本技能 `08-voice-toolkit.md` A 区 | 去 AI 味、精简、句型多样化 | 「这段台词太 AI 了」 | 自带支线，不外包 |

### D · 题材专精（覆盖通用规则）

| 技能 | 领地 | 优先于本技能的部分 |
|---|---|---|
| `infinite-thriller-scriptwriting` | 无限流、规则怪谈、中式恐怖、副本设计、恐惧节奏、付费卡点 | 副本机制、规则文本、恐惧节奏；本技能只保留排版与节奏表 |
| `sitcom-writers-room` | 情景喜剧、群戏、关系驱动幽默、角色声口 | 喜剧结构与包袱设计；`09` 的笑点 / 包袱周期仍适用，但结构听它的 |
| `microdrama-storyforge` | 15 集竖屏排产、成本控制、平台合规 | 集数规格与排产；本技能只在 70–80 集规格下说了算 |

## 三条常用连招

**连招 1 · 从一句话到可交付剧本**
`short-story-pitch`（可选立项）→ `script-craft-1-framework`（可选起架子）→ **本技能 工位 1 → 2 → 3** → `script-craft-4-dialogue`（逐句磨台词）→ 本技能 `check_format.py` + `check_rhythm.py`

**连招 2 · 成稿后挑毛病**
本技能成稿 → `script-craft-3-doctor`（圆桌会诊出优先级）→ `screenwriting-pro`（单人动刀）→ `l1ang-drama`（跨集连续性）→ 重跑两个校验脚本

**连招 3 · 文字稿到成片**
本技能 工位 3 → 工位 4 分镜 → `seedance-shotlist-director` 制作板 或 `manju-production-suite` 全流程 → `tig-acting-task` 补表演 → `tig-blocking-map` 定走位 → 视频提示词编译

## 冲突仲裁

| 争议 | 听谁的 | 理由 |
|---|---|---|
| 剧本排版格式 | **本技能 `04-format-spec.md`** | 只有它定义中国式 `△` / `场x-x` / 内心os / 闪回交付件 |
| 集内秒级节奏 | **本技能 `09-rhythm-grid.md`** | 单场有没有劲听 `tig-scene-engine`，多久给一次听 09 |
| 跨集连续性与台词时长 | `l1ang-drama` | 它的硬门禁与终审 QA 更专 |
| 逐句台词打磨 | `script-craft-4-dialogue` | 七维诊断带理由，比通用改写准 |
| 15 集竖屏排产 / 成本控制 | `microdrama-storyforge` | 规格不同，别用 70–80 集的骨架去套 |
| 无限流副本 / 规则怪谈设定 | `infinite-thriller-scriptwriting` | 题材专精优先于通用 |
| 情景喜剧结构 | `sitcom-writers-room` | 同上；笑点密度仍按 09 排 |
| 视频提示词、镜头、资产板 | E 组下游技能 | 本技能只产出文字，不越界 |

**总原则**：题材专精 > 通用；下游交付格式 > 上游方法；本技能只在「中文短剧文字交付件」这一段说了算。

## 交接协议

**交出去时带上**：集数规格与节奏档位、`04` 排版规范、人物表与身份字幕、已定稿的上游产物路径、本集时间轴（若有）。

**拿回来时必做**：
1. 跑 `scripts/check_format.py` —— 外部技能大概率不遵守 `△` / 场序 / 字幕规范；
2. 跑 `scripts/check_rhythm.py` —— 改写常把节奏锚点磨平；
3. 按 `SKILL.md` 硬规则 3 过一遍文风，确认没被带入博主腔或学术腔。

外部技能改完的稿子，**不校验不交付**。
