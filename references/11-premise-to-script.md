# 工位 0 · 主题立项（一句话主题 → 可拍剧本雏形）

## 何时启用

用户只给一个主题或一句话，例如「给我写个剧本，主题是重组家庭」「根据这个主题创作故事背景、人物和对话」。手上没有粗纲、没有分集梗概、没有小说原文。

**不要直接开 70 集大纲。** 先花最小成本做一个能读、能演的雏形，验证主题有没有戏，再决定要不要投生产线。跳过这一步直接排 70 集，第 20 集必然注水。

## 与生产线的接口

```
一句话主题 → [工位 0] 剧本雏形 → 出口判据 ─通过→ [工位 1] 70–80 集大纲 → 工位 2 → 工位 3 → 工位 4
                                          └不通过→ 改人物关系或改主题，别硬扩
```

工位 0 产出的剧本片段**同样是交付件**：必须按 `04-format-spec.md` 排版、按 `09-rhythm-grid.md` 排节奏。不许写成故事梗概、人物小传汇编或散文。

## 第一步 · 主题解码（把词变成戏）

主题词本身不是故事。填四栏，任一栏填不出**具体名词**，说明主题还只是标签，先别动笔。

| 栏位 | 要填什么 | 不合格的样子 |
|---|---|---|
| 主角要什么 | 一个可以被明确拒绝的具体东西 | 「想要幸福」 |
| 谁在挡 | 同一个东西的争夺者，有名字、有手段、有账本 | 「命运」「现实」「时代」 |
| 代价 | 输了会失去什么具体的东西 | 「失去一切」 |
| 情绪兑现 | 观众要看哪一种：爽 / 虐 / 燃 / 惧 / 暖 | 「感动」 |

四栏齐了才有对抗；缺一栏，写出来必然是议论文。

## 第二步 · 人物三件套

- **主角**：缺什么 / 怕什么 / 死不肯承认什么。第三条决定台词味道——嘴上说的必须和心里要的不一样。
- **对手**：与主角争同一个目标，不是「坏人」。他的动机要能用他自己的逻辑讲通，观众得听懂他为什么这么干。
- **绑定者**：把两人锁在同一空间、不能一走了之的人或物——母亲、孩子、婚约、合同、上下级、一套还没分完的房子。

写人物不写履历。只写两件事：他现在要做什么，为什么必须现在做。

## 第三步 · 背景一条压人的规则

时代 + 地点 + 一条具体的社会规则，这条规则要能压人：户口、彩礼、编制、家族面子、病房探视权、谁有资格签字。

背景不铺陈。靠一场戏里的道具与旁人的嘴交代完。`03-script-agent.md` 的灵堂示例是标准打法：宾客两句议论，把身份、抱错、逼嫁、死因全交代了，没有一句旁白。

## 第四步 · 对话戏（这就是交付件）

- 2–4 分钟，1–2 场，按 `04-format-spec.md` 排版。
- 必须发生一次**立场反转**：开场谁占上风，结尾换人。没有反转的对话叫聊天。
- 节奏按 `09-rhythm-grid.md` 排：张力轴（3 秒冲突 / 5 秒爆点 / 6 秒打脸位 / 30 秒反转）与喜剧轴（8–11 秒笑点 / 15 秒包袱）并行叠加，按题材取关闭项；每 35 秒内至少给一次 5–8 秒呼吸段，反转之后必给。
- 结尾停在**一个未闭合的动作**上，不总结陈词、不升华、不喊口号。

## 出口判据（能不能撑 70 集）

三条全过才进工位 1：

1. 主角欲求能分段升级，至少拆得出 7 个阶段性目标。
2. 对手每次失败都能换一种更狠的手段，不是重复同一招。
3. 每 10 集能换一档代价，**至少排得出 7 档**（示例链条：丢面子 → 丢工作 → 丢人 → 丢自由 → 丢退路 → 丢身份 → 丢所爱）。只写得出 4 档，说明这部剧撑到第 40 集就没牌了。

一条不过：**改人物关系，不要加新角色硬撑。** 加角色是最省事也最毁剧的解法——每加一个，主线就稀释一层。

## 直接调用模板

用户明确要求「按这个提示词来」时原样使用；否则按上面四步走。这两段是**起点**，产出物仍须过 `04` 排版与 `09` 节奏，不能直接当成品交。

**中文版**

> 我希望你能作为一个编剧。你将为一部长篇电影或网络剧开发一个吸引观众的有创意的剧本。首先要想出有趣的人物、故事的背景、人物之间的对话等。一旦你的角色发展完成——创造一个激动人心的故事情节，充满曲折，让观众保持悬念，直到结束。我的第一个要求是「剧本主题」。

**English**

> I want you to act as a screenwriter. You will develop an engaging and creative script for either a feature length film, or a Web Series that can captivate its viewers. Start with coming up with interesting characters, the setting of the story, dialogues between the characters etc. Once your character development is complete — create an exciting storyline filled with twists and turns that keeps the viewers in suspense until the end. My first request is '剧本主题'.

## 常见塌点

| 塌点 | 症状 | 修法 |
|---|---|---|
| 主题写成议论文 | 人物变成观点的传声筒，没有具体欲求 | 回第一步四栏，补「可以被拒绝的具体东西」 |
| 跳过雏形直接排 70 集 | 前 10 集还行，第 20 集开始注水 | 先写 2–4 分钟对话戏，验证完再扩 |
| 背景靠旁白交代 | 开场三分钟在讲设定 | 改成旁人议论，或一个道具特写 |
| 对话没有立场反转 | 两人各说各话，谁也没被逼退 | 给其中一方一个必须当场亮出的底牌 |
| 对手是纯坏人 | 观众看不懂他为什么这么干 | 写出他的账本：他失去过什么 |
| 一上来就加角色 | 人物表越写越长，主线越来越淡 | 删掉不争夺同一目标的角色 |
