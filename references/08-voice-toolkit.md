# 文风改写工具箱（A / B / C 三区隔离）

## 先做分区判定

| 用户说 | 用哪一区 | 允许作用的对象 |
|---|---|---|
| "这段台词太 AI 了""改口语一点""别那么书面" | **A 区** | 剧本台词、动作行、OS、分镜台词 |
| "改成公众号 / 小红书文案""像朋友聊天""加互动感" | **B 区** | 文案、解说词、推文 |
| "学术化""论文润色""引用格式""论点不够深" | **C 区** | 论文、研究报告、商务材料 |
| 没说明用途，只说"润色一下" | 默认 **A 区**，并先确认对象 | — |

## 硬边界（不可协商）

- **B 区与 C 区禁止进入剧本**的台词、动作行、`内心os`、`【字幕】`、分镜台词。依据 `SKILL.md` 硬规则 4。
- 剧本禁用词与句式：`哈哈`、`emmm`、`说实话`、`以我的经验`、`个人觉得`、`我之前试过`、`欢迎在评论区分享`、`有没有遇到过这种情况`、星巴克 / 咖啡馆场景、跑题与刻意重复、`赋能 / 闭环 / 全链路 / 多维度 / 底座 / 体系化`、`发挥了关键作用 / 提供了坚实基础 / 全方位强化`、排比阵型、口号式结语、"首先 / 其次 / 最后"三段论。
- 剧本台词标准：**短句、当代口语、带情绪钩子、能直接念出来**。情绪最重的那句往往最短。
- A 区的改写算子只用来"去掉机器味"，不用来把台词改长、改雅、改成复合句。凡是把简单句升级为复合句、把语言学术化的算子，一律归 C 区。
- 改写时**禁止脑补任何未经验证的细节**：维持原文的核心思想、客观事实与底层框架。剧情改写尤其不能凭空增加人物、道具或前史。

## A 区 · 去 AI 味（剧本可用）

### A1 基础降 AI 感提示词

对文本重写，核心目标是抹除机器生成的生硬感，使其读起来像一位职场老手亲笔撰写。要求：

1. 维持原文的核心思想、客观事实与底层框架，严禁脑补任何未经验证的细节；
2. 剔除假大空的废话、陈词滥调、机械式的对仗和过度排比；
3. 打破句式的绝对匀称，做到长短句交错分布；
4. 适度融入真实语境下的主观判断，以及符合人类习惯的自然过渡；
5. 字里行间需透出真人的思考过程，但拒绝过于口语化或粗俗的表达。

整体基调：严谨、沉稳、流畅自然。

> 用于剧本时，第 5 条的"不过于口语化"**反过来执行**——剧本要口语，但不要博主腔。其余四条照用。

### A2 针对中文语境的深度拟人化

把段落润色为极其地道的中文书面材料，彻底洗脱 AI 生成的刻板印象：

1. 砍掉标志性 AI 套话，例如"发挥了关键作用""提供了坚实基础""全方位强化"等车轱辘话；
2. 打破过于刻意死板的"三段论"、排比阵型和口号式结语；
3. 将虚浮的宏观论述降维，替换为具体的动作、痛点剖析或实操步骤；
4. 优化段与段之间的逻辑连接，禁止无脑使用"第一、第二、第三"或"首先、其次、最后"；
5. 守住原文的书面正式感，不改成充满网络梗或者过于陈述的口语。

### A3 ChatGPT 专用 · 脱机改写

对内容执行"脱机改写"。默认设定容易把文章搞得四平八稳、过度工整且充满模板感，因此必须遵守：

1. 克制使用排比句的冲动；
2. 摒弃把全部观点强制套入"背景—挑战—对策—收益"这种刻板八股结构的习惯；
3. 严禁堆叠"体系化、全链路、多维度、赋能、底座、闭环"等互联网黑话和高频大词；
4. 允许句式参差不齐，部分观点可以直接犀利地抛出；
5. 尽可能还原真实的业务场景、个人的主观研判；
6. 文本沉稳、真实可信，绝不能为了追求"像人"而显得轻浮草率。

需交付两个版本：**A. 严谨商务版** / **B. 随性自然、带有强烈个人色彩版**。

> 仅在用户明确要求"两个版本的改写文案"时启用；B 版产出的个人色彩文本不得回流进剧本。

### A4 DeepSeek 专用 · 去学术化重组

对段落进行"去学术化、去 AI 味"的重组，重拳打击"悬浮感"，要求向下扎根：

1. 拒绝任何形式的过度理论升华；
2. 把概念还原成具体的人、动作与场景，不用术语替代事实；
3. 删掉堆砌的定义、模型名与框架名，只保留能落到画面上的信息；
4. 允许观点以短句直接落地，不强制推演链条；
5. 保留具体数字、时间、地点与可核查细节，删掉无法验证的概括；
6. 收束时不写总结句、不喊口号，停在一个具体事实上。

> 原始素材在第 1 条后截断，第 2–6 条为按同一意图补全，便于直接调用。

### A5 可安全用于剧本的改写算子

| 目的 | 提示词 |
|---|---|
| 句型单一、重复 | 请帮我改写以下段落，使其句型更加多样化，避免重复：【段落内容】 |
| 用词不准 | 请协助我替换以下文本中的常见词汇，提升词汇丰富性：【文本内容】 |
| 句子衔接生硬 | 请帮我为以下句子添加适当的过渡词，增强段落连贯性：【句子列表】 |
| 内容冗余 | 请帮我精简以下段落，去除冗余和重复表达：【段落内容】 |
| 表达啰嗦 | 请帮我改写以下段落，确保语法正确且表达简洁：【段落内容】 |
| 语法与错字 | 请帮助我校对以下段落的语法和拼写错误，并进行必要的修正：【段落内容】 |
| 句子结构混乱 | 请协助我优化以下句子的结构，使其表达更清晰流畅：【句子列表】 |
| 逻辑不连贯 | 请帮我检查以下段落的逻辑连贯性，并提出改进建议：【段落内容】 |
| 段落之间断裂 | 请帮我检查并优化以下段落之间的逻辑连接：【段落A内容】与【段落B内容】 |
| 偏离主题 | 请协助我确保以下段落保持主题一致性，并避免偏离主要研究问题：【段落内容】 |

> 表中"化繁为简 / 精简 / 简洁 / 语法校对 / 逻辑衔接"类算子对剧本最有用；凡带"研究问题""主要研究"字样的提示词，调用时把措辞换成"本集核心冲突"。

### A6 剧本台词专用精简规则

从原始素材的"写作时注意"中拆出适用于剧本的部分：

- 多用短句，避免过于书面的词语。
- 可以用反问、感叹等口语化表达。
- 用具体的例子替代抽象的概念。
- 适当加入幽默元素——**仅在喜剧向剧集**，且靠情境反差，不靠网络梗。
- 台词要能直接念出来，念着拗口就重写。

原始素材中"28 岁新媒体博主 / 哈哈 / 星巴克 / 评论区互动"那一半，归入 B 区。

## B 区 · 真人闲聊 / 博主体（仅文案、解说词、推文）

**严禁用于剧本。** 完整保留原始素材，供改写公众号、小红书、种草文、解说词时调用。

### B1 轻松自然口语写作要求

- 用轻松自然的语气写作，把自己想象成一个 28 岁的新媒体博主，经常用"哈哈""emmm""说实话"这样的口语化表达。
- 最重要的是像一个真实的人在和朋友聊天；分享内容时加入自己的思考和经历，例如"我之前试过很多方法，最后发现…""说实话，这个方法我用了一个月才看到效果"。
- 想象正在星巴克喝咖啡，跟好朋友分享心得；用轻松的对话方式展开，适当加入生活化细节。
- 写作时经常和读者互动，例如"有没有遇到过这种情况？""说实话，我一开始也觉得…"，让文章有对话感。
- 用生活中常见的事物做比喻，例如"这就像煮饭""就像谈恋爱一样"，避免专业术语和书面语。
- 用轻松愉快的语气，让读者感觉在和一个有意思的朋友聊天，而不是在听课；可以适当开玩笑，但不要太正式。
- 段落之间用"说到这个""对了""还有一个有意思的事"过渡，避免生硬的"第一、第二"。
- 以讲故事的方式展开，可以是自己的经历，也可以是朋友的案例；好的故事都是具体的，不是抽象的道理。
- 结尾要有互动感，例如"你们有没有遇到类似的问题？""欢迎在评论区分享你的经历"，让读者有参与感。

### B2 打破工整逻辑结构

把 AI 味很重的文字改成真人闲聊的语气：打破原本工整的逻辑结构，适当加入跑题和重复，像朋友在跟你吐槽一样。关键地方加"说实话""以我的经验""个人觉得"这类口语词。

### B3 更像真人说话

1. 把长句拆短，穿插使用插入语；
2. 加入"吧""呢""啊"这种语气词；
3. 适当重复关键观点；
4. 用"搞""整""弄"替换书面语动词。

### B4 注入真人情绪与互动感

1. 在关键位置加入个人感受，例如"看到这个数据我第一反应是…"；
2. 预设读者疑问并用设问句回答，例如"你可能会说…但实际情况是…"；
3. 加入具体的生活细节和场景描述；
4. 适当使用 emoji（如果需要）。

## C 区 · 学术 / 论文 / 商务润色（仅论文与商务材料）

**严禁用于剧本。** 完整保留原始素材，供写论文、研究报告、商务材料时调用。

### C4 转述与引用的合规边界

原始素材里有一条标题为"让 AI 帮你洗白"的提示词。这里按合规用法重写，并划清边界：

> 请协助我重述以下段落，同时补齐规范引用与出处标注，确保学术严谨性：【段落内容】

用途边界：用于**正当的转述与引用规范化**。不得用于规避查重、掩盖未标注的引用来源，或把他人成果改写成原创表述。涉及他人观点、数据、图表时，必须保留可追溯的出处。

## 误用自查（交付前 10 秒）

- [ ] 台词里没有 B 区的博主腔、跑题、评论区互动、emoji
- [ ] 台词里没有 C 区的复合句、学术术语、论文腔、"首先其次最后"
- [ ] 改写没有脑补原文不存在的人物、道具、前史或数据
- [ ] 改写后短句更多、句子更短，而不是更长更雅
- [ ] 若交付的是文案或论文，已确认没有被当成剧本回流到主线
