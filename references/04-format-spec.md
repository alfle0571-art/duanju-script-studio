# 中文短剧剧本排版规范（硬规范）

本文件是交付件的排版标准。分集剧本的每一行都要能对上下面某一条规则；对不上的行，改写或删除。完整范例见文末。

## 速查表

| 元素 | 写法 | 位置 |
|---|---|---|
| 场序 | `场3-2 日/内 体育场 主要人物：张三、李四、王五` | 每个场景第一行，独占一行 |
| 动作 / 场景 / 特效 | `△` + 一句可拍摄的动作 | 动作行行首 |
| 对话 | `人物名：台词` | 独占一行 |
| 说话状态 | `人物名（慢慢转身）：台词` | 人物名后、冒号前 |
| 首次出场身份 | `【字幕：沈知初，厉家夫人】` | 挂在该人物第一或第二个画面行尾 |
| 群演豁免 | `（本集群演：司仪、宾客甲、路人甲）` | 集首单独一行，声明后免挂人物字幕 |
| 时间 / 地点信息 | `（时间字幕：1987年）` | 紧跟相关动作行，不写成 `【字幕：…】` |
| 内心活动 | `沈知初内心os：……` | 独占一行 |
| 闪回 | `【闪回】` … `【闪回结束】` | 成对，包裹完整场次 |
| 特写 / 强调信息 | `（化验单特写：胃癌晚期）` | 紧跟相关动作行 |

## 逐条规则

### 1 · `△` 动作行

除了对话以外，场景、动作、状态描写都要在行首加 `△`。需要时补上详细的特效或特写说明。

```
△沈知初手里拿着病例报告一步步踏上天台楼梯。
△她捂着嘴咳嗽两声，再一看手心，满是鲜血。
△医生将病例报告递给沈知初，沈知初接过。
△厉景深疾步上了天台，带着怒意喊了沈知初一声。
△沈知初绝望地走出诊室，被疾步走来的护士撞了也麻木着不回头。
```

一条 `△` 只写一个可拍摄的动作。多个连续动作拆成多行，便于后续拆镜。

### 2 · 人物对话

直接用人物名加冒号，不加引号、不加"说道"。

```
医生：抱歉沈小姐，你的诊断结果是胃癌晚期，我们已经尽力了。
厉景深：给我好好履行你的职责！
```

### 3 · 说话时的情绪与动作

写在人物名后的括号里，括号内容是可演出来的动作或可听出来的语气。

```
沈知初（慢慢转身）：如果有一天，我快死了，你会不会想我啊。
厉景深（逼近，一把握住沈知初的手腕）：明玥受伤了，跟我去医院。
沈知初（一把甩开他的手，带着哭腔）：景深！我快死了，没时间再讨好你了，我也不想去帮你给她输血了。
厉景深（愠怒）：合同白纸黑字写的很清楚，只要他需要你就得无偿献血！
```

禁止在括号里只写"悲伤地""愤怒地"这类抽象标签；把具体表情交给 `△` 动作行，词从 `06-emotion-library.md` 取。

### 4 · 人物出场字幕

人物出场说明必须在该人物出现的**第一个或第二个画面**给出标注，形式为 `【字幕：姓名，身份】`，挂在对应画面行尾。

```
△她捂着嘴咳嗽两声，再一看手心，满是鲜血。【字幕：沈知初，厉家夫人】
厉景深（逼近，一把握住沈知初的手腕）：明玥受伤了，跟我去医院。【字幕：厉景深，厉氏总裁】
```

字幕写身份，不写性格形容词；身份要在当下剧情里能被观众理解。

**谁不必挂字幕**：群演与功能性配角（司仪、宾客、路人、护士、服务员）不挂人物字幕，在集首用一行 `（本集群演：司仪、宾客甲、路人甲）` 声明，校验脚本据此豁免。**年代、地点这类信息不是人物身份**，写成 `（时间字幕：1987年）` 这种特写行，不用 `【字幕：…】` 格式——否则会被当成一个叫「1987 年」的角色。

**位置要求**：`【字幕：…】` 必须挂在该人物的第一或第二个画面行尾；如果人物先以动作出场、到第二句台词才说话，字幕就挂在那个说话行尾。同一个镜头里不并排挂两条人物字幕。**同一角色全篇只挂一次**——换集再挂一遍，交付件里会出现两次同名字幕。

### 5 · 内心活动

用 `内心os` 加冒号，独占一行。保持短句，不写大段独白。

不要写成 `沈知初（OS）：……` 或 `沈知初 OS：……`：前者会被当成一句**台词**交给配音，明明是心里话却念出声；后者连人物名都解析不出来，整行在制作环节丢失。只有 `内心os` 这一个写法。

```
沈知初内心os：厉景深，如你所愿，我要放过你了……
沈知初内心os：厉景深，我这次真的要……
沈知初内心os：果然，他从来没有爱过我，我只不过是他青梅竹马的移动血库罢了。
```

### 6 · 闪回 / 回忆杀 / 倒叙

用 `【闪回】` 与 `【闪回结束】` 成对包裹，内部仍要写完整场序。闪回结束后回到主线场次，必要时再写一次主线场序。

```
【闪回】
场1-2 日/内 诊室 主要人物：沈知初、医生
△医生将病例报告递给沈知初，沈知初接过。
医生：抱歉沈小姐，你的诊断结果是胃癌晚期，我们已经尽力了。
△沈知初绝望地走出诊室，被疾步走来的护士撞了也麻木着不回头。
沈知初内心os：厉景深，我这次真的要……
【闪回结束】
```

### 7 · 场序

场序即场景次序，每一个拍摄场景都要标明。一集可能只有一场，也可能两三场；由于短剧每集时间短，**每集最多五个场景**，要尽可能减少场景转换，增加剧情流畅度。

格式：

```
场x-x 天气/场景 地点 主要人物：xxx、xxx、xxx
```

- 第一个数字是集数，第二个是该集内的场次序，从 1 连续递增，不断号、不重复。
- `天气/场景` 写作 `日/内`、`日/外`、`夜/内`、`夜/外` 等。
- 例：第三集第二场，白天在室内体育馆拍学生打球 → `场3-2 日/内 体育场 主要人物：张三、李四、王五`。

## 完整范例

```
第一集
场1-1 日/外 天台 主要人物：沈知初、厉景深
△沈知初手里拿着病例报告一步步踏上天台楼梯。
（化验单特写：胃癌晚期）
沈知初内心os：厉景深，如你所愿，我要放过你了……
△她捂着嘴咳嗽两声，再一看手心，满是鲜血。【字幕：沈知初，厉家夫人】
【闪回】
场1-2 日/内 诊室 主要人物：沈知初、医生
△医生将病例报告递给沈知初，沈知初接过。【字幕：医生，主治医生】
医生：抱歉沈小姐，你的诊断结果是胃癌晚期，我们已经尽力了。
△沈知初绝望地走出诊室，被疾步走来的护士撞了也麻木着不回头。
沈知初内心os：厉景深，我这次真的要……
【闪回结束】
△沈知初苦笑着放下满是鲜血的手。
△厉景深疾步上了天台，带着怒意喊了沈知初一声。
沈知初（慢慢转身）：如果有一天，我快死了，你会不会想我啊。
厉景深（逼近，一把握住沈知初的手腕）：明玥受伤了，跟我去医院。【字幕：厉景深，厉氏总裁】
沈知初（一把甩开他的手，带着哭腔）：景深！我快死了，没时间再讨好你了，我也不想去帮你给她输血了。
厉景深（愠怒）：合同白纸黑字写的很清楚，只要他需要你就得无偿献血！
△厉景深说完，一把掐住沈知初的脖子。
沈知初内心os：果然，他从来没有爱过我，我只不过是他青梅竹马的移动血库罢了。
厉景深：给我好好履行你的职责！
△厉景深扯着沈知初就走，病例报告从沈知初的手里落在了地上。
```

> 范例相对原始稿件只做了两处技术性修正：明显错别字（「秦梅竹马」→「青梅竹马」）、给遗漏的「医生」补上首次出场【字幕】，使其符合本文件第 4 条规范并能通过 `scripts/check_format.py` 校验。剧情、台词与排版保持原样。注意它示范了三件事：开场三行内交代绝症与身份、【闪回】补背景不打断主线、结尾用掉落的病例报告留钩子。

## 常见错误清单

| 错误 | 改法 |
|---|---|
| 场序写成 `1-1 日内灵堂` | 写 `场1-1 日/内 灵堂 主要人物：…` |
| 场序断号或重复 | 按集内顺序重排，从 1 连续递增 |
| 一集写了 7、8 个场景 | 合并到 ≤5 个，把对话挪进同一场 |
| `【闪回】` 没有 `【闪回结束】` | 补闭合标记 |
| 角色说了三句台词还没挂字幕 | 在第一或第二个画面行尾补 `【字幕：…】` |
| `△` 行里写"内心悲痛""气氛压抑" | 换成可见动作与微表情 |
| 括号里写"（悲伤）""（愤怒）" | 换成具体动作或语气，例如（一把甩开他的手，带着哭腔） |
| 一条 `△` 塞进三个动作 | 拆成三行 |
| 内心os 写成半屏独白 | 压到一两句短句，其余交给动作与台词 |
| 内心活动写成 `沈知初（OS）：……` / `沈知初 OS：……` | 统一写 `沈知初内心os：……`，否则会被当台词配音或整行丢失 |
| 同一角色挂了两次 `【字幕：…】` | 全篇只留第一次，重复挂会让成片出现两次同名字幕 |
| 说话状态用半角括号 `司念(坐起身)：` | 中文剧本统一全角：`司念（坐起身）：` |
| 台词里出现"说实话""哈哈""赋能" | 删除，见 `SKILL.md` 硬规则 4 |
| 说话状态写成 `司念：（坐起身）唉，吵死了！` | 括号前移到冒号前：`司念（坐起身）：唉，吵死了！` |
| 场序写成 `场1-1日内灵堂`（场号后缺空格） | 补空格：`场1-1 日/内 灵堂 主要人物：…` |
| 年代写成 `【字幕：1987年】` | 改成 `（时间字幕：1987年）`，否则会被当成一个叫「1987 年」的角色 |
| 两人拉扯、拥抱写在同一个 `△` 里 | 剧本阶段可写，但进入工位 4 分镜时必须拆成单人特写 / 正反打 |

## 与校验脚本的对应

`scripts/check_format.py` 检查：场序存在性与连续性（含场号后缺空格）、`△` 行格式与抽象情绪词、说话状态是否写在冒号前（含半角括号）、`内心os` 写法（含 `（OS）` / `角色 OS：` 两种误写）、闪回成对、每集场景数、有台词角色的字幕覆盖与重复挂字幕（群演声明豁免）、年代误写成人物字幕、B/C 区禁用词。脚本只做结构校验，不判断文笔；文笔与情绪按 `SKILL.md` 的自检清单人工过一遍。
