# 秒级节奏密度表

短剧不是把情节写快，是**按秒给观众发情绪**。本文件把六条口诀转成可排布、可检查的时间轴。

口诀原文：**3 秒一冲突、5 秒一爆点、6 秒一巴掌、15 秒一个包袱、30 秒一个反转、每 8–11 秒一个笑点。**

## 先说三条判断（不理解这三条，照抄口诀会写坏）

**1. 六条是两条并行轴，不是排队执行。**

| 轴 | 锚点 | 观众身上的反应 |
|---|---|---|
| 张力轴 | 冲突 3s / 爆点 5s / 巴掌 6s / 反转 30s | 想知道下一秒会发生什么，身体前倾 |
| 喜剧轴 | 笑点 8–11s / 包袱 15s | 想笑、想截图、想转发 |

同一秒可以同时命中两轴：一句反呛既是「冲突」也是「笑点」。排时间轴时两轴各排各的，最后叠在同一条时间线上。**不要把六个周期相加**，也不要按顺序轮转。

**2. 「3 秒一冲突」是密度上限，不是数量指标。**

含义是：观众任意时刻往回看 3 秒，都得看到对抗**仍在升级**。一个持续加码的冲突可以覆盖多个 3 秒窗口（对方逼近 → 主角后退 → 撞到桌角 → 手里攥紧了东西），不必每 3 秒换一个新矛盾。同理「5 秒一爆点」的爆点可以是微爆点：一个眼神、一句反呛、杯子磕在桌上的一声响，不等于每 5 秒来一场大场面。

按字面排 90 秒 30 个冲突，结果必然是人物没有喘息、动机来不及成立、观众情绪钝掉。

**3. 「6 秒一巴掌」是可替换位，不是真扇耳光。**

它指的是**打脸 / 反击爽点落地**的那个位置。按题材替换：

| 题材 | 该位置放什么 |
|---|---|
| 打脸爽剧 | 一句噎死对方的话、证据甩在桌上、身份亮牌 |
| 虐恋 / 情感 | 对方被一句话钉在原地、主角第一次不接电话 |
| 悬疑 / 无限流 | 规则反噬、证据打脸、对方自己说漏嘴 |
| 喜剧 | 自食其果、误判被当场戳破 |

连续真扇耳光有两个问题：一是撞平台暴力合规，与 `05-storyboard-pipeline.md` 的「降维 + 音效代偿」原则直接冲突；二是三集之后观众就麻了。**字面出现「扇耳光 / 掌掴」时，按 `05` 降维成侧面暗示 + 精准音效。**

## 六个锚点的精确定义

| 锚点 | 周期 | 本质 | 必须可落到 | 反例 |
|---|---|---|---|---|
| 冲突 | ≤3s | 有人想要的东西被挡住，且阻力在变大 | 一个可见动作或一句挡回去的话 | 「气氛紧张起来」 |
| 爆点 | ≤5s | 信息或情绪强度突变，观众有身体反应 | 特写、声响、一句短台词 | 「内心翻涌」 |
| 巴掌 | ≤6s | 打脸 / 反击爽点落地（可替换位） | 对方的具体反应（微表情从 `06` 取） | 真扇耳光连着来 |
| 笑点 | 8–11s | **即时逗笑**，单次反应，不需要铺垫 | 一句反差台词、一个失态动作 | 讲一个完整段子 |
| 包袱 | ≤15s | **铺垫 + 抖响**的完整喜剧结构 | 前面埋、此处响，两处都要标 | 把笑点当包袱 |
| 反转 | ≤30s | 集内认知被改写，观众对刚才那段的判断失效 | 一条新信息或一次立场翻转 | 「事情没那么简单」 |

**笑点与包袱的区别**：笑点是当场就笑，包袱要先埋后响。15 秒的包袱里通常已经含了一个 8–11 秒的笑点，两者可以重叠但不互相替代。一集至少留一个完整包袱，别全靠零散抖机灵。

## 三个尺度不要混（另有一个 t=0 特例）

| 尺度 | 规则出处 | 管什么 |
|---|---|---|
| **集内秒级** | 本文件 | 30 秒反转、6 秒巴掌等，一集之内的情绪密度 |
| **单镜时长** | `05-storyboard-pipeline.md` | 文戏 2–5 秒、情绪爆发 5–8 秒，是「格子」的长度 |
| **跨集宏观** | `01-outline-agent.md`、`07-hit-rules.md` | 每 8–12 集一次中型反转、全季三个主反转、相邻两集不重复爽点 |
| **开局 t=0** | `07-hit-rules.md` 规律一 | 第一集前三行的反常理钩子，是张力轴在 0 秒的特例 |

集内 30 秒反转 ≠ 全季第 35–45 集的主反转。前者改的是「这一秒观众以为谁赢」，后者改的是「整部剧到底在讲什么」。写大纲时只管后者，写细纲与剧本时才排前者。

「6 秒一巴掌」也不等于镜头必须 6 秒。一个 6 秒窗口里可以是三个 2 秒的短镜（正反打 + 反应特写）。

## 单集时间轴模板

用 `assets/节奏时间轴模板.md` 起稿，每个动作节点带时间码。下面是 90 秒满档示例（题材：真假千金 / 打脸爽剧），注意两轴叠加与呼吸段：

| 秒位 | 张力轴 | 喜剧轴 | 具体落点 |
|---|---|---|---|
| 00:00 | 钩子 + 冲突 | — | 追悼会上，婆婆当众撕了化验单 |
| 00:03 | 冲突升级 | — | 婆婆把碎片摔在女主脸上，逼她当场道歉 |
| 00:05 | 爆点 | — | 女主抬眼，眼神从麻木转冷（微表情：阴沉脸） |
| 00:06 | 巴掌位 | 笑点 | 女主：「撕了吧，原件在律师那儿。」婆婆僵住 |
| 00:09 | 冲突 | 笑点 | 小姑子插嘴帮腔，被女主一句话噎回去 |
| 00:12 | 爆点 | 包袱铺垫 | 男主推门进来，手里拿着同一份文件的第二份 |
| 00:15 | — | 包袱抖响 | 婆婆刚才那句「原件只有一份」被原样奉还 |
| 00:18 | 呼吸段 | — | 静音两秒，只给婆婆手指攥紧碎片的手部特写 |
| 00:24 | 冲突 | — | 婆婆改口说女主伪造，人群开始议论 |
| 00:28 | 爆点 | 笑点 | 律师进门，喊的是女主的名字 |
| 00:30 | **反转** | — | 这份文件真正要证明的不是病情，是股权 |
| 00:33 | 呼吸段 | — | 女主没说话，只把碎片一张张捡起来 |
| 00:38 | 冲突 + 巴掌位 | — | 婆婆伸手要抢，被女主先一步按住 |
| 00:45 | 爆点 | 包袱铺垫 | 女主报出一串日期，婆婆脸色变了 |
| 00:48 | 呼吸段 | — | 女主停下，只听见婆婆的呼吸声 |
| 00:52 | — | 笑点 | 小姑子悄悄往后退了半步 |
| 00:58 | 冲突 | 包袱抖响 | 那串日期正是婆婆当年签字的日子 |
| 01:05 | 爆点 + 巴掌位 | — | 人群转向，婆婆被围在中间 |
| 01:12 | 呼吸段 | — | 空镜：地上还剩半张没捡的碎片 |
| 01:20 | **反转** | — | 女主把最后一张碎片递给婆婆：「这个，您留着。」 |
| 01:27 | 结尾钩子 | — | 手机亮起，备注是「爸」 |

**注意呼吸段出现在反转之后、下一轮升级之前**。删掉它们，后面所有爆点都会失效。

60 秒单集：把上表压到 00:00–01:00，保留 00:00 钩子、00:06 巴掌位、00:15 包袱、结尾钩子；呼吸段留 1 个，放在 00:30 反转之后。**60 秒要两个反转**——第二个反转就是结尾钩子，只排一个就违反 30 秒周期。
120 秒单集：按 30 秒一个循环扩到 4 轮，每轮一个反转，最后一轮反转必须同时是结尾钩子。

## 按题材调节密度（重要）

这套满档配置是**竖屏打脸爽剧 / 喜剧向**的。70–80 集里每集都满档，观众会疲劳，人物弧光也没地方长。

| 题材 | 张力轴 | 喜剧轴 | 说明 |
|---|---|---|---|
| 打脸爽剧 | 满档 | 中 | 默认档，反转可略降频，保住打脸密度 |
| 喜剧向 / 轻喜 | 满档 | 满档 | 两轴都开，包袱必须完整 |
| 虐恋 / 情感 | 冲突与爆点保留，巴掌位减半 | **关闭或极低** | 笑点会戳破情绪；把巴掌位换成「一句话钉住对方」 |
| 悬疑 / 无限流 | 反转优先，冲突不断 | **关闭** | 巴掌位换成证据打脸或规则反噬；喜剧交给 `infinite-thriller-scriptwriting` 判断 |
| 年代 / 正剧 | 整体降一档 | 关闭 | 呼吸段加长，给表演留空间 |

**校验器档位对应**：`--mode full` 是打脸爽剧默认档，喜剧轴按「中」密度（包袱 ≤45s）；`comedy` 是喜剧向满档，按 15 秒包袱、8–11 秒笑点严格查；`romance` / `suspense` 关闭喜剧轴；`light` 对应降档集。**选错档位会把合格稿子判成不合格**，跑校验前先定题材。

**反转怎么查**：按 30 秒周期、容差 45 秒，且把「最后一个反转到片尾」计入。所以 90 秒单集至少三个反转（最后一个可以与结尾钩子同位），只排一个会被判超期——这是刻意收紧，否则「开头一个反转、后面全靠对话」的稿子能蒙过去。

**全季密度曲线**：每 10 集一个叙事单元（见 `01-outline-agent.md`），单元高潮集用满档，过渡集降一档，每单元留 1 集「呼吸集」专门铺人物关系与伏笔。大纲阶段就要给每集标出档位，不要等写剧本时才发现全季都是满档。

## 呼吸段是硬要求，不是节奏松了

密不透风 → 观众没时间消化 → 情绪反而钝。规则：

- 每 25–35 秒安排一次 **5–8 秒低密度段**：一个沉默特写、一个空镜、一句短台词、一个手部动作。
- **反转之后必须给**，让新信息落地。`scripts/check_rhythm.py` 对此判 ERROR；若反转本身就是结尾钩子（距片尾不足 12 秒），自动豁免。
- 呼吸段里不排新冲突，但可以让旧冲突的余温继续（比如对方还在发愣）。
- 分镜上用 5–8 秒长镜或慢动作承接，别用碎切。

## 落到四个工位

| 工位 | 节奏规则怎么落 |
|---|---|
| 工位 1 · 大纲 | 给每集标「节奏档位」（满档 / 降档 / 呼吸集），画出全季密度曲线；只管跨集反转，不管集内秒级 |
| 工位 2 · 细纲 | **每个动作节点带时间码**，用 `assets/节奏时间轴模板.md` 出一集完整时间轴，跑 `scripts/check_rhythm.py` |
| 工位 3 · 剧本 | 时间码**不写进剧本正文**（保持 `04-format-spec.md` 干净），但每场戏对应时间轴的一段；台词按秒压缩，单句 ≤20 字 |
| 工位 4 · 分镜 | 把时间轴锚点映射到镜头，一个锚点至少一镜；锚点密集处用 2–5 秒短镜，呼吸段用 5–8 秒；巴掌位如涉肢体接触按 `05` 拆单人特写 / 正反打 |

## 常见错误

| 错误 | 改法 |
|---|---|
| 把六条当排队轮转 | 两轴并行，同一秒可叠加 |
| 90 秒排 30 个独立冲突 | 一个持续升级的冲突覆盖多个 3 秒窗口 |
| 每 6 秒真扇一次耳光 | 换成可替换位；涉暴力按 `05` 降维 + 音效代偿 |
| 把笑点当包袱 | 包袱要「前面埋、此处响」，两处都标 |
| 集内 30 秒反转写成全季主反转 | 分清尺度，集内只改当下判断 |
| 全程满档不留呼吸 | 每 25–35 秒插 5–8 秒低密度段，反转后必给 |
| 虐恋剧里硬塞 8 秒一笑点 | 按题材调节，喜剧轴可关闭 |
| 时间码写进剧本正文 | 只写在细纲与时间轴表里，剧本保持 `04` 格式 |
